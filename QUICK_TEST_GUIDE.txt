🚀 TO START:
   python simulation_gui_voice.py

📝 WHAT TO EXPECT:

1. GUI Window Opens
   ├─ Title: "🤖 PHQ-9 HEALTH SCREENING SIMULATION"
   ├─ Status: Shows Voice Mode ON/OFF, GPT ON/OFF
   └─ Green Button: "▶ START SCREENING"

2. Click START SCREENING
   ├─ Robot speaks consent (3 parts, ~15 seconds)
   ├─ Explains: "This is NOT psychological evaluation"
   ├─ Says: "For technical demonstration only"
   └─ Gives instructions: "Answer with not at all, several days..."

3. For Each of 9 Questions:
   ├─ Robot asks question (voice + text)
   ├─ YOU RESPOND:
   │   ├─ 🎤 Click red "PRESS TO SPEAK" button, then speak
   │   └─ ⌨️ OR type in text field and press Enter/Send
   ├─ Robot acknowledges: "I see, several days. That's recorded as 1."
   └─ Robot says: "Let me ask you the next question."

4. After Question 9:
   ├─ Robot thanks you
   ├─ Announces total score: "Your score is X out of 27"
   ├─ States severity: "This indicates [minimal/mild/moderate/...] level"
   ├─ Explains what that means
   └─ Reminds: "This is technical demonstration only"

5. Export Data:
   └─ Click "📊 Export Logs" to save CSV file

═══════════════════════════════════════════════════════════════════════

🎤 VOICE INPUT TIPS:

✓ Wait for "🔴 LISTENING..." to appear
✓ Speak clearly at normal pace
✓ Say answers like:
  - "Not at all"
  - "Several days"
  - "More than half the days"
  - "Nearly every day"
  - Or just say: "Zero", "One", "Two", "Three"

✓ If voice fails → Just type your answer instead

═══════════════════════════════════════════════════════════════════════

📊 VALID ANSWERS (Score 0-3):

0 = Not at all / Never
1 = Several days / Sometimes  
2 = More than half the days / Often
3 = Nearly every day / Always
