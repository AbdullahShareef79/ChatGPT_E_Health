# Quick Setup Checklist

Follow these steps to reproduce the PHQ-9 Simulation environment:

## Prerequisites
- [ ] Python 3.10+ installed (tested with Python 3.12)
- [ ] Git installed
- [ ] OpenAI API key (get from https://platform.openai.com/api-keys)

## Setup Steps

### 1. Clone Repository
```bash
git clone https://github.com/AbdullahShareef79/ChatGPT_E_Health.git
cd ChatGPT_E_Health
```

### 2. Create Virtual Environment
```bash
# Windows
python -m venv venv
venv\Scripts\activate

# macOS/Linux
python3 -m venv venv
source venv/bin/activate
```

### 3. Install Dependencies
```bash
pip install -r requirements.txt
```

**If PyAudio fails on Windows (Python 3.12+):**
```bash
pip install pipwin
pipwin install pyaudio
```

### 4. Configure API Key
```bash
# Copy example file
cp .env.example .env

# Edit .env and add your API key:
# OPENAI_API_KEY=sk-proj-your-actual-key-here
# GPT_ENABLED=True
```

### 5. Run Simulation
```bash
# English version
python experiments_and_simulations/simulation_gui_voice.py

# German version
python experiments_and_simulations/simulation_gui_voice_de.py
```

## Troubleshooting

### PyAudio Installation Issues
- **Error:** "No module named 'distutils'"
  - **Solution:** Use pipwin or download pre-built wheel from https://www.lfd.uci.edu/~gohlke/pythonlibs/#pyaudio
  - **Note:** Voice input won't work without PyAudio, but text input will

### TTS (Text-to-Speech) Issues
- **English version speaking German?**
  - **Fixed:** Latest version automatically selects English voice
  - **Manual fix:** Install English TTS voice from Windows settings

### API Key Issues
- **Error:** "No OpenAI API key found"
  - **Solution:** Ensure `.env` file exists in project root with valid API key
- **Error:** API calls failing
  - **Solution:** Verify API key is active at https://platform.openai.com/api-keys

## Verification

After setup, you should see:
- GUI window opens with "PHQ-9 Pepper Simulation"
- Status bar shows "Voice Mode: ON/OFF | GPT: ON"
- Green "START SCREENING" button enabled
- Red "PRESS TO SPEAK" button (if PyAudio installed)

## What Gets Ignored by Git

The following are NOT committed to the repository:
- `.env` (contains your API key)
- `venv/` (virtual environment)
- `experiments_and_simulations/data/` (session data)
- `*.csv` files (interaction logs)
